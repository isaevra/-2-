# Мой день

Telegram Mini App: личный и семейный дашборд — мысли, привычки, финансы, дела и календарь.
Бот присылает напоминания о событиях и делах и утреннюю сводку.

## Как устроено

- `index.html` — мини-апп (один файл, без сборки).
- `src/worker.js`, `src/lib.js` — сервер на Cloudflare Workers (бесплатный тариф):
  - хранит данные: личный раздел у каждого и общий раздел «Семья»;
  - каждую минуту проверяет напоминания и время утренней сводки;
  - раз в 30 минут подтягивает операции из Дзен-мани (если подключён в «Финансах»);
  - принимает сообщения боту: любой текст сохраняется в «Мысли», `/today` — сводка, `/invite` — пригласить в семью.
- `wrangler.toml` — настройки воркера. Имя воркера в Cloudflare: **my-day**.

Если открыть `index.html` не через бота (например, с GitHub Pages), приложение работает локально, без сервера.

## Первичная настройка

1. Cloudflare → Workers & Pages → Create → Import a repository → этот репозиторий. Имя проекта: `my-day`. Deploy.
2. Воркер → Settings → Variables and Secrets → Add → тип **Secret**, имя `BOT_TOKEN`, значение — токен от @BotFather.
3. Открыть `https://my-day.<твой-поддомен>.workers.dev/setup` — подключит бота, кнопку меню и команды.
4. В Telegram открыть бота и нажать Start: первый, кто нажмёт, становится владельцем.
5. Пригласить жену: в приложении ⚙️ → «Пригласить в семью» (или команда `/invite` боту).
